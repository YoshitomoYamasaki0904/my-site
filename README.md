# Yoshitomo Yamasaki — Personal Website

このフォルダは GitHub Pages にそのままアップロードできる静的サイトです。

## ファイル
- index.html — トップページ
- music.html — Music
- writing.html — Writing
- drawing.html — Drawing
- thought.html — Thought
- style.css — 共通スタイル
- script.js — スマホ用メニュー
- images/ — 画像を入れるフォルダ

## GitHub Pages
1. GitHubで新しいPublic repositoryを作成
2. このフォルダ内のファイルとimagesフォルダをrepositoryの一番上にアップロード
3. Settings → Pages
4. Source: Deploy from a branch
5. Branch: main / (root)
6. Save
7. 数十秒〜数分待つと公開URLが表示されます

## 画像について
現在のトップページは画像がなくても表示できるよう、仮のビジュアルになっています。
自分の画像を使う場合は、images/main.jpg を置いて style.css の .hero-image を背景画像に変更してください。

Drawingページの作品画像も、必要に応じてHTMLを画像表示に変更できます。
